# Bundled theme palettes

Palettes only (colors are mapped onto serpis UI roles in `src/themes.rs`).

- `modus.json`: the eight Modus themes by Protesilaos Stavrou, extracted from
  `modus-themes.el` as shipped with GNU Emacs 31.1 (GPL-3.0-or-later). Semantic mappings
  (e.g. `bg-region`, `fg-added`) are resolved to hex values.
- `github.json`: the GitHub themes from projekt0n/github-nvim-theme (MIT), evaluated from
  its palette/spec files (Primer colors).
